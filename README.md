# Bioinformatics Course Exercises

This repository contains exercises and assignments completed as part of my undergraduate bioinformatics course.

## Topics Covered

- Linux and Ubuntu
- Bash and command-line tools
- Git and GitHub
- Python
- NumPy
- pandas
- Matplotlib
- Jupyter Notebook
- Basic machine learning
- Biological and genomic data processing

## About the Course

The exercises were completed during my undergraduate studies in Molecular Biology and Physiology.

The course provided practical experience with programming, command-line tools, data analysis, and basic bioinformatics workflows.
